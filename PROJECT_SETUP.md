# HOUSE AI — Windows 11 PowerShell Setup & Operations Guide

This guide provides step-by-step instructions for configuring, training, running, and testing **HOUSE AI** on Windows 11 using Windows PowerShell.

---

## 1. System Prerequisites

1. **Operating System:** Windows 11
2. **Node.js:** v18 LTS or newer (verified with Node.js v25.2.1)
3. **Python:** Python 3.11 (`C:\Users\pankaj\AppData\Local\Programs\Python\Python311\python.exe`)
4. **MongoDB:** MongoDB Community Server running locally on `mongodb://127.0.0.1:27017` (or a MongoDB Atlas URI configured in `backend/.env`)

---

## 2. Environment Variable Configuration

### Backend (`backend/.env`)
Copy `backend/.env.example` to `backend/.env`:
```env
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/houseprice_ai
JWT_SECRET=replace_with_a_secure_random_secret
ML_API_URL=http://127.0.0.1:8000
CLIENT_URL=http://localhost:5173
NODE_ENV=development
```

### Frontend (`frontend/.env`)
Copy `frontend/.env.example` to `frontend/.env`:
```env
VITE_API_URL=http://localhost:5000/api
```

## 3. Step-by-Step Installation & ML Training

### Step 3.1 — Python Machine Learning Environment Setup
Open Windows PowerShell and run:
```powershell
cd "C:\Users\pankaj\OneDrive\Documents\Antigravity\HOUSE AI\ml-model"

# Create Python 3.11 virtual environment (if not already created)
& "C:\Users\pankaj\AppData\Local\Programs\Python\Python311\python.exe" -m venv venv

# Activate virtual environment
.\venv\Scripts\Activate.ps1

# Install required ML packages
python -m pip install -r requirements.txt

# Generate India Location Master dataset (28 States + 8 UTs)
python generate_location_master.py

# Train and benchmark ML models (Linear Regression, Random Forest, Gradient Boosting)
python train.py

# Run Python ML unit & integration tests
python -m unittest tests/test_ml_service.py -v

# Start the Flask ML microservice on http://127.0.0.1:8000
python app.py
```

### Step 3.2 — Node.js + Express Backend Setup
Open a second Windows PowerShell window and run:
```powershell
cd "C:\Users\pankaj\OneDrive\Documents\Antigravity\HOUSE AI\backend"
npm install
npm run dev
```
The backend will start on `http://localhost:5000`, connect to `mongodb://127.0.0.1:27017/houseprice_ai`, and automatically seed the `locations` (`820` records) and `modelresults` collections.

### Step 3.3 — React + Vite Frontend Setup
Open a third Windows PowerShell window and run:
```powershell
cd "C:\Users\pankaj\OneDrive\Documents\Antigravity\HOUSE AI\frontend"
npm install
npm run dev
```
Open `http://localhost:5173` in your browser.

## 6. Troubleshooting

1. **MongoDB Connection Refused (`ECONNREFUSED 127.0.0.1:27017`):**
   Ensure the MongoDB Windows service is running (`Start-Service MongoDB` in an elevated PowerShell prompt) or update `MONGO_URI` in `backend/.env` to point to your active MongoDB instance.
2. **Python ML Service Unreachable (`http://127.0.0.1:8000`):**
   Ensure `python app.py` is running inside `ml-model` with the `venv` virtual environment activated, and that `models/best_house_price_model.joblib` has been generated by `python train.py`.
3. **PowerShell Execution Policy Warning when Activating `venv`:**
   If `.\venv\Scripts\Activate.ps1` is blocked by Windows Execution Policy, run:
   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\venv\Scripts\Activate.ps1
   ```
